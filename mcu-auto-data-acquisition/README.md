# 单片机自动数据采集系统

基于 STC15F2K60S2 的多通道模拟量采集与显示系统（综合创新实践）。

## 功能

- **电压采集**：GPIO 模拟 I²C 驱动 PCF8591（8 位 ADC）采集电压
- **温度采集**：1-Wire 协议读取 DS18B20 数字温度传感器
- **显示**：定时器中断动态扫描 8 位数码管
- **交互**：矩阵按键切换电压 / 温度显示模式
- 74HC573 锁存器 + ULN2003 驱动继电器、蜂鸣器等外设

## 硬件

| 模块 | 型号 | 接口 |
|---|---|---|
| 主控 | STC15F2K60S2 | — |
| ADC | PCF8591 | 软件模拟 I²C |
| 温度 | DS18B20 | 1-Wire |
| 显示 | 8 位数码管 | 定时器扫描 |

## 目录结构

```
.
├── src/               # C 源码（main.c + 各模块 .c/.h）
│   ├── main.c         # 主逻辑：按键调度、显示模式切换
│   ├── i2c_hw.c/.h    # GPIO 模拟 I²C
│   ├── pcf8591.c/.h   # ADC 驱动
│   ├── ds18b20.c/.h   # 温度传感器驱动
│   ├── ledseg.c/.h    # 数码管扫描显示
│   ├── keyboard.c/.h  # 矩阵按键
│   ├── timer.c/.h     # 定时器中断
│   ├── led.c/.h       # LED 指示
│   └── delay.c/.h     # 延时
├── keil/              # Keil 工程文件
│   └── pcf8591.uvproj
└── hex/               # 编译产物
    └── pcf8591.hex
```

## 构建

用 Keil C51 打开 `keil/pcf8591.uvproj` 编译即可，构建结果 **0 Error、0 Warning**。

## 说明

- I²C 采用 GPIO 模拟，未使用硬件 I²C 外设，便于移植到任意引脚。
- 默认 IRC 时钟 12 MHz。
