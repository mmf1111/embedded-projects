# STC15 电压与温度采集显示系统

基于 STC15F2K60S2 的电压与温度采集显示系统（综合创新实践）。

## 功能

- **电压采集**：GPIO 模拟 I²C 驱动 PCF8591（8 位 ADC）；主循环连续读取两次，并按 5 V 参考电压换算显示值
- **温度采集**：按 1-Wire 时序读取 DS18B20，处理正负温度显示
- **显示**：定时器中断动态扫描 8 位数码管
- **交互**：矩阵按键切换电压 / 温度显示模式
- 初始化时关闭 ULN2003 所接蜂鸣器、继电器等外设，避免影响采集显示

## 硬件

| 模块 | 型号 | 接口 |
|---|---|---|
| 主控 | STC15F2K60S2 | — |
| ADC | PCF8591 | 软件模拟 I²C |
| 温度 | DS18B20 | 1-Wire |
| 显示 | 8 位数码管 | 定时器扫描 |

## 目录结构

```
.
├── src/               # C 源码（main.c + 各模块 .c/.h）
│   ├── main.c         # 主逻辑：按键调度、显示模式切换
│   ├── stc15.H        # STC15 寄存器定义
│   ├── i2c_hw.c/.h    # GPIO 模拟 I²C
│   ├── pcf8591.c/.h   # ADC 驱动
│   ├── ds18b20.c/.h   # 温度传感器驱动
│   ├── ledseg.c/.h    # 数码管扫描显示
│   ├── keyboard.c/.h  # 矩阵按键
│   ├── timer.c/.h     # 定时器中断
│   ├── led.c/.h       # LED 指示
│   └── delay.c/.h     # 延时
├── keil/              # Keil 工程文件
│   └── pcf8591.uvproj
├── Doc/               # 原工程附带的实验接线说明
└── hex/               # 编译产物
    └── pcf8591.hex
```

## 构建

用 Keil C51 打开 `keil/pcf8591.uvproj`。仓库已补入原始工程所需的 `stc15.H`，并将工程文件中的源文件路径改为当前的 `src/`。原始工程的构建记录为 **0 Error、0 Warning**；本次整理环境没有 Keil C51，需在 Windows/Keil 中重新编译确认。

## 说明

- I²C 采用 GPIO 模拟，未使用硬件 I²C 外设，便于移植到任意引脚。
- 默认 IRC 时钟 12 MHz。
