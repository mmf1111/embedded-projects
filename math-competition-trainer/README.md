# 竞赛数学训练场 · 非数学 A 类

面向全国大学生数学竞赛（非数学 A 类）的专项与真题训练网页，支持随机刷题、收藏和完成进度记录。

## 功能

- **知识点专项刷题**：9 章横向切换，每章按「定义 / 定理前提 / 公式 / 二级结论 / 易错点」构建冲奖知识链
- **历年真题专区**：按年份折叠、逐题查看解析
- **随机刷题**：生成无重复随机队列，可按全部专项 / 仅真题 / 指定章节抽题
- **收藏与进度**：收藏 + 完成记录，共 394 题，进度条实时统计

## 技术栈

- HTML / CSS / JavaScript（原生，单文件，无构建、无后端）
- [MathJax](https://www.mathjax.org/) 渲染 LaTeX 公式
- `localStorage` 本地保存收藏与完成进度
- 响应式布局，适配桌面与移动端

## 运行

直接用浏览器打开 `index.html` 即可，无需任何依赖或部署。
