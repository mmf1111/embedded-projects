# 物联网智能避障小车

基于 Arduino 的多功能小车，支持**音乐、循迹、避障**三种模式，并通过蓝牙串口遥控。

## 功能

- **音乐模式**：蜂鸣器播放《夜的钢琴曲 5》
- **循迹模式**：红外传感器沿黑线循迹，丢线超时自动处理
- **避障模式**：红外避障 + "后退—转向—脱困"逻辑，减少卡死
- **蓝牙遥控**：串口蓝牙收发 `F/B/L/R` 等指令控制前进、后退、转向

## 硬件

| 模块 | 型号 / 说明 |
|---|---|
| 主控 | Arduino Nano（ATmega328P） |
| 电机驱动 | L293D |
| 循迹 / 避障 | 五路红外传感器 |
| 输出 | 蜂鸣器、直流电机 |
| 通信 | 串口（115200）+ 蓝牙 |

## 目录结构

```
.
├── firmware/
│   ├── smart_car.ino        # 完整版（音乐 + 循迹 + 避障 + 蓝牙）
│   └── versions/            # 历史迭代版本
│       ├── code2.ino
│       ├── code3.ino
│       └── code4.ino
└── pcb/
    └── 何凡2400301238主板.eprj   # 立创 EDA 专业版 PCB 工程
```

## 说明

- 主控板为独立完成的两层 PCB（立创 EDA 工程见 `pcb/`），完成制板、焊接与整车联调。
- 通过 UART 9600 输出传感器值与动作状态，配合万用表、示波器完成电源、红外载波和电机驱动排查。

## 运行

用 Arduino IDE 打开 `firmware/smart_car.ino`，选择 Arduino Nano 上传即可。
