# 多模式智能小车

基于 Arduino Nano / ATmega328P 的实车项目，完成主控板 PCB 打样焊接、整车装配和遥控、循迹、避障功能联调。

## 功能

- **遥控与音乐**：串口/蓝牙命令 `F/B/L/R/S` 控制前进、后退、左转、右转、停车，蜂鸣器播放音乐
- **循迹**：左右红外传感器识别黑线；丢线后短时向前搜索，超过 100 ms 仍未识别到则停车等待
- **迷宫避障**：读取左、前、右传感器；前方受阻时择空侧转弯，死胡同时后退、转向；另有后退—转向—前进脱困流程
- **模式切换**：整合代码中以 `1/2/3` 切换音乐、循迹、避障模式

## 硬件

| 模块 | 型号 / 说明 |
|---|---|
| 主控 | Arduino Nano（ATmega328P） |
| 电机驱动 | L293D |
| 循迹 / 避障 | 五路红外传感器 |
| 输出 | 蜂鸣器、直流电机 |
| 通信 | 串口（整合代码 115200）+ 蓝牙 |

## 目录结构

## 说明

- 主控板为双层 PCB（立创 EDA 工程见 `pcb/`），已完成制板、焊接与整车联调。
- 循迹问题通过调节红外传感器模块灵敏度、观察串口状态并反复实车测试定位。
- `firmware/versions/` 保留分别验证遥控音乐、循迹和避障的原始版本；整合版来自课程文档，原文档末尾截断，仓库版补齐了轻转向、停车和遥控映射函数。补齐后的版本已做语法检查，尚需在实车上再次确认。

## 运行

用 Arduino IDE 打开 `firmware/smart_car/smart_car.ino`，选择 Arduino Nano（ATmega328P）进行编译与上传。蓝牙串口按整合代码设置为 115200 波特率。

若需复现原始功能，可分别查看 `firmware/versions/` 中的三个独立草图。
